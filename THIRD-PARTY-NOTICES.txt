src/CodeBrix.Imaging/Formats/Jxl/Encoder/Entropy/JxlPrefixEncoder.cs adapts

Encoder/Entropy/JxlAnsEncoder*.cs adapts the ANS histogram normalization,
precision search, histogram serialization and symbol coder in lib/jxl/enc_ans.cc,
enc_ans.h and ans_common.h at the same revision. It inverts the shared managed
alias table for encoding. Managed histogram cost estimates use double-precision
logarithms; the normalization step retains upstream fixed-point entropy deltas.
The managed normalizer explicitly prevents used bins from shrinking below one
state while repairing an initially nonpositive balancing bin after rounding.
Encoder/Entropy/JxlLz77.cs adapts token cost estimation, hash-chain matching,
repeat parsing and dynamic-programming refinement from lib/jxl/enc_lz77.cc at
the same revision. Managed changes include absolute chain positions, effort
dependent search limits, double-precision cost estimates, long-periodic-run
bounds and final selection by actual encoded bit count. The special-distance
table is shared with the jxl-oxide-derived managed decoder.
Greedy rejected-match skipping follows ApplyLZ77_LZ77 in enc_lz77.cc;
managed chain comparisons are additionally limited to 65,536 samples per
candidate. Both bounds prevent repeated scans of cheaply coded periodic input.
Encoder/Entropy/JxlHistogramOptimizer.cs adapts versioned priority-queue
histogram merging and the prefix single-symbol merge penalty from
lib/jxl/enc_cluster.cc, and hybrid-integer candidate configurations and their
selection from enc_ans.cc at that revision. Managed merge ranking uses bounded
histograms and double-precision estimates; final selection compares complete
encoded bit counts, including configuration and context-map overhead.
Eight-byte token storage, zero-copy traversal of grouped token arrays in
JxlTokenSequence.cs, and bounded distinct-value collection for configuration
selection are original managed changes by Jeremy Ellis and contributors.
After 65,536 distinct values, configuration selection accumulates the same
candidate histograms directly, preserving exhaustive candidate costs.
Encoder/JxlEncoderPreflight.cs is original managed admission control for
encoder working-memory estimates and frame-section limits. Its estimates cover
managed tokens, retained candidate streams, imported planes, raw features and
metadata; it uses the separately attributed frame geometry without altering
the requested coding tools. Encoder workspace exception classification and
early JPEG coefficient-allocation checks are original integration changes.
Encoder/Entropy/JxlEntropyEncoder.cs adapts context-map move-to-front,
entropy and run-length candidate selection from lib/jxl/enc_context_map.cc
and enc_ans_params.h at the same revision. The managed writer compares actual
bit counts for simple, prefix, ANS and run-length representations, with bounded
recursion for the two-context run-length model's own context map.
For more than 256 input contexts, distant-seed selection and nearest-cluster
assignment follow FastClusterHistograms in enc_cluster.cc before pair merging.
All input distributions are retained until clustering; context-index modulo
grouping is only a baseline candidate, never the input to the optimized search.
Encoder/Entropy/JxlPermutationEncoder.cs adapts Lehmer-rank tokenization from
lib/jxl/enc_coeff_order.cc at the same revision, using a managed Fenwick tree
for bounded O(n log n) work. Headers/JxlFrameToc.cs uses it for reordered TOCs.
Encoder/VarDct/JxlXybEncoder.cs adapts the linear-sRGB-to-XYB absorbance matrix,

VarDct/JxlDequantMatrices.Encode.cs inverts the attributed jxl-oxide raw

the Modular image is narrow/tall, and its flattened coefficient layout is

Encoder/VarDct/JxlNoiseEstimator.cs adapts flat-patch SAD selection,

JxlLossyPatchEncoder.Dots.cs adapts the two Gaussian guidance filters,

Encoder/VarDct/JxlVarDctPreparation.cs adapts initial DC/AC quantization,

Encoder/VarDct/JxlVarDctInput.cs is original integration of the attributed

Encoder/VarDct/JxlCoefficientOrder.cs adapts zero-frequency sorting, natural

Encoder/VarDct/JxlChromaFromLuma.cs adapts the initial 8x8 and final selected-

Encoder/VarDct/JxlPhotonNoise.cs adapts the sensor/ISO noise model and LUT

Encoder/VarDct/JxlChromaticityQuantization.cs adapts the distance thresholds,

PixelStatsForChromacityAdjustment and ComputeChromacityAdjustments in
